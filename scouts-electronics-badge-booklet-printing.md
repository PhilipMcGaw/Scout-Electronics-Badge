A reference for formatting and printing the electronics badge booklet as a folded booklet from Microsoft Word.

## Points to check when reading

- Configure Word's **Book fold** page layout.
- Check paper size and finished booklet size (for example, A4 sheets folded to A5).
- Set suitable margins and gutter.
- Configure double-sided printing and page orientation; check printer capabilities and manual duplex instructions if needed.
- Print and inspect a test copy before producing the full booklet.
