Resistor code calculator

Decode common through-hole resistor colour bands and surface-mount resistor markings. Select the marking scheme that matches the part. The result is an interpretation, so check the resistor’s datasheet when the value matters.

Through-hole colour bands

For 4 bands, the first two bands are significant digits. For 5 or 6 bands, the first three are significant digits. The next band is the multiplier, followed by tolerance; a sixth band commonly gives temperature coefficient.

Surface-mount marking

Examples: 3-digit 103 = 10 kΩ; 4-digit 1002 = 10 kΩ; R notation 4R7 = 4.7 Ω; EIA-96 01C = 100 Ω.

SMD marking systems are not universal. Some resistors have no marking, and a similar-looking code can mean something different for another series or manufacturer. Confirm the code against the exact datasheet or bill of materials.

Tolerance codes and band conventions can vary. A colour band calculator cannot identify the resistor’s power rating, working voltage, temperature coefficient or exact series.
