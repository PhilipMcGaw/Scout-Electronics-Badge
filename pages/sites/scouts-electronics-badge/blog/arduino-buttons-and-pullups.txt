====== Arduino buttons: reading a reliable digital input ======

A pushbutton looks simple: press it, and an Arduino should notice. The key is to make sure the input pin has a defined voltage when the button is open. If the pin is left unconnected, it can pick up electrical noise and read unpredictably. This is called a **floating input**.

===== Give the input a default state =====

A pull-up or pull-down resistor gently connects the input to a known voltage when the button is not pressed. A pull-up connects it towards the board’s logic supply; a pull-down connects it towards ground. When the button is pressed, the circuit changes the pin to the opposite state.

Many Arduino boards provide an internal pull-up resistor that can be enabled in software with ''INPUT//PULLUP''. For a compatible board, connect a momentary button between a digital input pin and GND, then set that pin to ''INPUT//PULLUP''. The input reads ''HIGH'' while the button is open and ''LOW'' when pressed. This is called **active-low** logic: the action is represented by a low signal. Check the board documentation before relying on an internal pull-up, because Arduino boards do not all use the same microcontroller or electrical limits.

===== Internal or external pull-up? =====

For a simple button connected between an input and GND, an internal pull-up is usually the easiest option. You enable it in software, so there is no separate resistor to fit and wire. That saves a component and keeps the circuit compact.

An external resistor gives you more control over the circuit. You choose its value, and you can use it as a pull-up or a pull-down. It also holds the input at a defined level while the microcontroller is reset or before the program enables an internal pull-up, provided the pin is high-impedance in that state. Check the exact board or microcontroller documentation.

^ Consideration ^ Internal pull-up ^ External resistor ^
| Extra parts | No separate resistor | Adds a resistor and its connections |
| Resistance | Set by the microcontroller; the value varies by device | You select a value that suits the circuit and input limits |
| Default during reset | May not be enabled until the program configures it | Can set the input level before the program starts, if the pin is high-impedance |
| Wiring options | Commonly pulls the input towards the logic supply | Can pull towards the logic supply or GND |

A lower external resistance makes a stronger pull and can make a long or noisy input less sensitive to interference, but it also increases current while a button connected to the opposite rail is held down. The right value depends on the circuit; check the microcontroller’s input limits and the board guidance. Do not assume that adding both internal and external pull-ups leaves the resistance unchanged: they act in parallel, giving a lower total resistance.

The two arrangements give opposite readings:

^ Circuit ^ Button open ^ Button pressed ^
| Pull-up to the logic supply; button to GND | ''HIGH'' | ''LOW'' |
| Pull-down to GND; button to the logic supply | ''LOW'' | ''HIGH'' |

In either circuit, the resistor holds the input at its default level while the button is open. When pressed, the button creates a path to the opposite rail. For equal resistor values and the same supply, a pull-up and pull-down draw the same current while held: with ''3.3 V'' and ''10 kΩ'', ''I = V ÷ R = 0.33 mA''. When open, there is ideally no complete path through the pull resistor, apart from small input leakage. Internal pull-resistor values and input leakage vary by board, so check the board documentation if power use matters.

<code>
const byte buttonPin = 2;
const byte ledPin = LED_BUILTIN;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  const bool pressed = (digitalRead(buttonPin) == LOW);
  digitalWrite(ledPin, pressed ? HIGH : LOW);
}
</code>

This sketch turns the built-in LED on while the button is pressed. It assumes the selected board has a built-in LED and supports ''INPUT_PULLUP''; use its board page and pinout to confirm. A different circuit, such as one with an external pull-down resistor, gives the opposite readings, so adapt the condition to match the wiring.

===== One press can look like several =====

The contacts inside a mechanical button can briefly open and close several times as a button is pressed. A program that counts every transition may interpret one press as several. This is called **switch bounce**. If a button simply holds an LED on while pressed, the quick transitions are usually not important. If the program reacts once per press, add a debounce method and test it with the actual switch.

One simple software method accepts a new reading only after it has stayed unchanged for a short interval. This example uses ''millis()'' so the program does not stop to wait. The ''50'' millisecond interval is an example; choose and check a suitable interval for the switch and the response the project needs.

<code>
const byte buttonPin = 2;
const byte ledPin = LED_BUILTIN;
const unsigned long debounceInterval = 50;

bool stableButtonState = HIGH;
bool lastReading = HIGH;
unsigned long lastChangeTime = 0;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  const bool reading = digitalRead(buttonPin);

  if (reading != lastReading) {
    lastChangeTime = millis();
    lastReading = reading;
  }

  if (millis() - lastChangeTime >= debounceInterval) {
    stableButtonState = reading;
  }

  digitalWrite(ledPin, stableButtonState == LOW ? HIGH : LOW);
}
</code>

The sketch assumes a momentary button wired between the input and GND with ''INPUT_PULLUP'', and a board with a built-in LED. The LED follows the debounced button state. A more complex program can act on a change from the previous stable state to detect one press or release event.

===== Check the board’s limits =====

Keep input voltages within the limits for the exact board. Do not connect a pin to a voltage above its supply rail or below ground. A microcontroller input is for sensing a signal; it is not a power output for motors, lamps, or other loads. Check the board and component documentation before connecting a circuit.
